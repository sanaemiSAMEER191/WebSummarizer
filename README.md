#  WebSummarizer

WebSummarizer is an AI-powered web scraping and summarization tool that extracts visible text from webpages and generates concise summaries using Transformer-based Seq2Seq models (BART).

##  Features
- Robust web scraping using BeautifulSoup
- User-Agent based request handling
- Text cleaning and preprocessing
- Transformer-based summarization (BART)
- Flask-powered web interface

##  Tech Stack
- Python
- Flask
- BeautifulSoup
- HuggingFace Transformers
- PyTorch

##  How to Run
```bash
pip install -r requirements.txt
python app.py
